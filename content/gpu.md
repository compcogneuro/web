**GPU** = _graphical processing unit_, which is a dedicated type of computer hardware that executes many instructions in parallel, operating on parallel data streams. This results in significantly faster processing for parallel neural network models relative to a standard serial _CPU_ (central processing unit). The ability to leverage GPU hardware for neural network models, popularized by the [[@^KrizhevskySutskeverHinton12]] _AlexNet_ paper, is critical for making it possible to train and run the current [[large language models]].
