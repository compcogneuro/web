This is the **style guide** and rationale for the style choices.

* **Bold** the first mention of the page name, hopefully within first sentence or paragraph.

* Generally use _emphasis_ (italics) for introduction of new terms (that are not other pages), except for particularly central terms, that can be in **bold**. There should not be more than 5 or so such bolded terms.

* Provide the link to other pages upon first mention, and not thereafter, unless there has been a significant distance since the last link, and it is of particular relevance.

* Try to keep the paragraphs as short as possible, with each distinct point in its own paragraph. 

* Try to start with the big picture points, with minimal scholarly backup, and add later sections with more detailed discussions etc. 

## Figures

* Use **bold** **A**, **B**, **C** etc for the sub-panels in figures, in both the figure and the caption. However, when referring to the figure panel in the text use the lower-case letter because 1a looks better than 1A. It is a basic "capitalize the start" principle: in the caption, a bold capital letter can stand alone as the start of the discussion of that panel, without any additional syntax. And in the figure, it is more typical to use the capital, and it stands out etc. When used after the figure number, it is not the start, so lower-case makes sense.

## References

APA-style references are generated, because then if you are familiar with the literature, you don't need to click on anything to know what is being referenced. It is _really_ inefficient on the reader to use arbitrary numbers. 

You are responsible for the parentheses, and the default reference is formatted to go inside parentheses: `([[@StrunkWhite09]]):` ([[@StrunkWhite09]]). Use semicolon ; to separate multiple parenthetical references. For a direct "subject" reference, use `[[@^StrunkWhite09]]:` [[@^StrunkWhite09]]. In general parenthetical references are preferred.

## Section headings

Use the `##` second-level section heading and below for all within-page headings, as the `#` top-level heading is reserved for the page itself. 

Headings are formatted left-justified, with font size being the primary indicator of level. This contradicts APA style for the top-level heading within a page (e.g., `##`), which is centered: the centering is too hard to see and inconsistent with the other headings.

Use Sentence case for heading text (not Title Case): this also contradicts APA but is more readable and sensible -- only the title needs title case!
