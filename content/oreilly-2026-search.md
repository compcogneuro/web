Every cognitively relevant type of computation can be cast as form of search:

* _Problem solving_ can be defined as search through _problem space_, as in many classical symbolic artificial intelligence (AI) systems ([[@NewellSimon72]]; [[@Newell90]]).

* _Planning_ is search through _action space_ to accomplish a desired outcome, which is the focus of many approaches in model-based reinforcement learning.

* _Learning_ is search through _representation space_, to find the best basis space for representing inputs, that supports the desired computational processes and behavioral outputs.

* _Inference_ is search through learned representations to find the best _interpretation_ of a given input stimulus relative to the stable semantics of the environment.

* _Evolution_ is search through _phenotype space_, e.g., as in genetic algorithms.

This is not an empty tautology, because it provides a unified understanding about the central problem faced in all of these domains: Each of these search spaces is plagued by the curse of dimensionality, and effective solutions for real-world, large-scale problems must somehow tackle the exponential explosion problem. 

Indeed, the field of computational complexity provides a unified framework based fundamentally on the process of search, that formally quantifies the computational cost of different types of problems through the use of universal Turing machines ([[@AroraBarak09]]). The core distinction here is in terms of _polynomial_ (P) versus exponential time costs, where polynomial means that the compute time is _on the order of_ (expressed as $O(f(n))$) a _constant_ exponential factor of the dimensionality of the problem space (e.g., $O(n^2)$ where the polynomial factor is 2). By contrast, exponential time means that $n$ is instead in the exponent, e.g., $O(2^n)$, which is where the exponential explosion problem occurs as $n$ increases, making these problems _intractable_.

Computational complexity theory defines an equivalence class across a wide range of problems, known as _NP complete_, where NP stands for _nondeterministic polynomial_ time. The terminology is not particularly intuitive, but the NP complete class defines a large set of _decision problems_ that require _exhaustive, enumerative_ (i.e, _brute force_) search over an exponentially-large space of possible solutions, where each decision evaluates a binary (yes or no) function, which itself runs in polynomial time (which accounts for the _P_ in _NP_). 

Formally, the NP class is defined in terms of a _nondeterministic Turing machine_ (which is where the _N_ in _NP_ comes from) which effectively performs a brute-force search process over a space of deterministic Turing machines, each of which runs its evaluation function in polynomial time. The more general _NP hard_ designation is not restricted to binary decision problems -- the _complete_ equivalence class only applies to such problems that can all be reduced to being effectively notational variants of each other. Most cognitively relevant computations such as Bayesian inference and optimal decision making are at least in the NP-hard class ([[@vanRooijWrightWareham12]]).

The framing of computational problems as search provides a crucial, intuitive insight into why some problems are exponentially costly, and others are not. In effect, if there is no efficient way to narrow the search space, then there is no other alternative to performing the brute force search through all possible states. If there _were_ an efficient, systematic way to narrow the search process, then it could potentially move from the NP complete class to the tractable P class.

An illustrative case is the classic _travelling salesman problem_ (TSP), which involves finding the minimal distance route between a set of $n$ randomly-distributed cities, which is in the NP complete class. However, TSP can be solved in polynomial time _if_ there is an underlying metric space (e.g., Euclidean distances) and the optimality constraint is relaxed, so that a solution only need be within some factor of the shortest distance of a route between the given cities ([[@Arora98]]). Interestingly, either of these constraints alone is insufficient. The resulting algorithm indeed involves an efficient way of narrowing the search space by dividing it into different subregions and applying a novel search constraint on those regions.

If there is no way to systematically narrow the search space, it must serially enumerate all relevant combinations to find the best solution, resulting in combinatorially exponential (i.e., NP) worst-case behavior (e.g., the target ends up being the last combination considered, like finding a needle in a haystack). **B** In a dedicated-weight-gradient-search (DWGS) algorithm like a neural network, each unit is dedicated to a specific feature value, and synaptic weights capture all interactions. In this context, we can understand the _stochastic gradient descent_ procedure in neural network models (e.g., [[@RumelhartHintonWilliams86]]) as a uniquely powerful way of searching exponentially-large combinatorial feature spaces ([[#figure_search]]), because the gradient-descent process provides a highly efficient way of shaping the direction of the search process toward more optimal solutions. As in the TSP problem, the success of this gradient descent procedure depends on operating within a system and environment that has some kind of underlying _metric_ properties within a space that is fundamentally _smooth_ enough, such that incremental graded steps are able to accumulate over iterations, and move ultimately toward a search solution. Furthermore, this process can only produce _local minima_ in the relevant optimization metric, i.e., approximately-optimal solutions, not the absolute global optimal solution.

These key differences from the standard NP-complete version of the search process, plus the basic limitations imposed by the neural network formalism itself, ensure that gradient descent in neural networks does not provide the long-sought example of an NP-complete problem that can be solved in polynomial time (i.e., proving that NP = P). This is the same logic for why [[@^Arora98]] also does not prove that NP = P. Nevertheless, in the _real world_, we are much more interested in the empirical capabilities of algorithms on large-scale problems of practical relevance, where there is no doubt of the relevance.

The success of extremely large (billions of parameters) neural-network based artificial-intelligence (AI) models depends entirely on the efficacy of this gradient-descent process. The importance of this efficient search process can also be seen in the negative case, in terms of the inability to scale up earlier symbolic AI models, for which a smooth metric gradient is undefined: symbols and the propositional structures in which they are used have discrete, "sharp" edges and many discontinuities. Furthermore, although the variational inference procedure enables gradient descent to be used on probabilistic (e.g., Bayesian) models ([[@BleiKucukelbirMcAuliffe17]]), there are still limitations in such models that prevent the kind of deep scaling possible in simpler, more linear neural network models.

It is also critical to emphasize the _no free lunch_ proscription against a generally optimal learning algorithm ([[@VapnikChervonenkis71]]; [[@GemanGeman84]]): gradient descent only works when gradients are actually useful for search, which represents a kind of _bias_ in the algorithm, that can easily be violated and thus result in very bad performance. Empirically, it is nevertheless evident that gradient descent in neural networks is effective for a wide range of relevant problems, and recent work is making progress analyzing why this is so ([[@LeePanageasPiliourasEtAl19]]; [[@DauphinPascanuGulcehreEtAl14]]; [[@NakkiranKaplunBansalEtAl21]]; [[@Shwartz-ZivTishby17]]; [[@VidalBrunaGiryesEtAl17]]).

In the context of a neural network, the gradient-descent search process can operate on two different variables, which correspond to different effective timescales of search:

* **Weights:** (i.e., _learning_) as in the error backpropagation algorithm, which configures weights to shape the internal representations of the network over the course of many learning trials to optimize the overall objective function. In modern AI models, the objective is often the ability to predict the next element in a sequence.

* **Activations** (i.e., _inference_) within an individual learning trial, which also contributes at least in part to various types of search listed at the outset, including planning and problem-solving. This can be performed using backpropagation to activation states, or via a _constraint satisfaction_ settling process as in the original _Hopfield_ network or _Boltzmann Machine_ ([[@Hopfield82]]; [[@HopfieldTank85]]; [[@AckleyHintonSejnowski85]]).

    This more rapid time scale of search process is not typically used in current large AI models, which are based on strictly feedforward architectures that do not support this form of search. Instead, this functionality is captured in part by the attention mechanism in transformers ([[@VaswaniShazeerParmarEtAl17]]) and cascading effects across multiple deep layers ([[@McClellandHillRudolphEtAl20]]). Nevertheless, it is likely that this inner-loop of constraint satisfaction search is critical for human intelligence, and, interestingly, many theories of consciousness involve a central element of this kind of recurrent, interactive processing (e.g., [[@Lamme06]]; [[@TononiKoch15]]).

In summary, the main point of this paper is simply to provide the broad conceptual framework articulated above, with the empirically-backed conclusion that stochastic gradient descent in weighted neural-network architectures may represent a uniquely powerful form of search, which can be seen as the central process involved in all major cognitive functions. This perspective also highlights the potential importance of the shorter time scale constraint-satisfaction search process to support inference, planning and problem-solving, which is missing in current large-scale AI models.

In the remaining sections, current research on gradient descent in learning and constraint satisfaction processing is reviewed, including new experimental results that point to important benefits of biologically-based neural network properties, including discrete spiking, surround inhibition, and the restriction to positive-only weights and activation states.

## The unreasonable efficacy of gradient descent

The gradient descent procedure used in error backpropagation represents a straightforward application of the chain rule, which is part of the basic toolkit of elementary calculus, as many students learn in high school. Therefore, it does not represent any kind of advance at the basic mathematical level, as emphasized by the historical treatment of the field by [[@^Schmidhuber25]], which cites Godfried Liebnitz (1676) as the earliest person to "discover" backpropagation, followed by a long list of other uses of similar procedures in statistical models. However, as [[@^Schmidhuber08]] himself earlier noted, it is the _last_ inventor that, by definition, has taken the credit, and in this case that is clearly [[@^RumelhartHintonWilliams86]], who went on to systematically articulate the computational advantages of this learning mechanism within a comprehensive framework that represented a paradigm shift across multiple fields.

Part of the reason that this gradient descent procedure was multiply reinvented in the context of neural network models (e.g., [[@Werbos74]]) is that nobody with experience in the use of this simple algorithm thought it would be successful, including Hinton and Rumelhart ([[@AndersonRosenfeld00]]). This is because there is too much risk of this procedure getting stuck in suboptimal _local minima_. We now understand more about why it does not generally suffer from this problem, in ways that also help to recognize that the remarkable success of gradient descent in neural networks is not likely to generalize to other contexts. Thus, there is something special about this combination of gradient descent and neural network models, and the environments upon which they've generally been applied.

One line of analysis has shown that instead of local minimal, most critical points in a neural network are likely to be _saddle points_ ([[@DauphinPascanuGulcehreEtAl14]]), but in fact these saddle points are almost always avoided by first-order gradient descent methods ([[@LeePanageasPiliourasEtAl19]]). Furthermore, the final convergence states tend to be near global optima ([[@ChoromanskaHenaffMathieuEtAl15]]).

A number of related results point to the broader conclusion that neural networks operate largely like _linear_ systems ([[@SaxeMcClellandGanguli13]]), despite the critical presence of a nonlinearity in their activation functions, which is necessary to obtain any benefit from multiple cascaded ("deep") layers. Indeed, the widespread adoption of the rectified linear activation function (ReLU) makes these models even closer to the linear limit, although its benefits may be more associated with its wide dynamic range and the elimination of the vanishing gradient problem.

As the size and depth of a neural network is increased, learning speed improves as roughly a power law ([[@BahriDyerKaplanEtAl24]]; [[@KaplanMcCandlishHenighanEtAl20]]), and, counterintuitively, generalization also improves ([[@NakkiranKaplunBansalEtAl21]]). One important cause of these effects is the ability of larger models to more faithfully capture the statistical structure of their inputs early in the training phase, so that all of the relevant signal is retained and available for then mapping onto the relevant output patterns ([[@Shwartz-ZivTishby17]]). 

Intuitively, it seems that the _central limit theorem_ effects (i.e., the "law of large numbers") cause these large models to have less variance in their behavior as a result of incremental weight changes, which then allows gradient changes to have a _smooth_, cumulative effect, even with the stochastic sampling effects of training on small batches of training items. By contrast, weight changes in smaller networks can have more dramatic effects on network behavior, making the gradient surface rougher.

## Weights vs configuration space

The formal computational complexity framework is based on _enumerative_ and _exhaustive_ search, which means that all possible combinations of the different elements in the space are considered (e.g., all possible routes through the cities, in the TSP problem). By analogy with an analogous situation in quantum physics, we can refer to this enumerative and exhaustive space as _configuration space_: the space of all possible configurations of a set of elements. The serial, computationally universal Turing machine framework has no difficulty with expressing the processing of configuration space.

However, the use of synapse-like weight parameters in neural networks represents a massive simplification of the search space relative to configuration space, because in most standard neural network models, the weights are used to compute a linear sum of weighted inputs, which imposes significant restrictions relative to any possible logical function that could be computed. While it is true that an entire multilayer neural network is a universal function approximator ([[@HornikStinchcombeWhite89]]; [[@SchaferZimmermann06]]), that does not mean that each individual neuron can be trained to compute any function on its inputs.

Furthermore, as noted above, the success of the gradient descent search process depends on the quasi-linear properties of individual neurons, so introducing more complex functional forms within individual neurons runs the risk of negating the entire advantage of the neural network framework in the first place. Indeed, research on neurons with multiplicative elements shows that a range of non-gradient-descent based optimization techniques are required, and it is unclear what the scaling properties of these networks are ([[@SwapnaRekhaNayakBehera20]]; [[@GaoZhouWangEtAl19]]). This is a potentially important source of caution relative to the widespread interest in the advanced computational capabilities provided by active channel properties within dendritic arbors (([[@HausserMel03]]; [[@MiglioreHoffmanMageeEtAl99]]; [[@PoiraziBrannonMel03]]; [[@JarskyRoxinKathEtAl05]]; [[@Spruston08]]; [[@PoiraziPapoutsi20]]).

Thus, it appears that the representational limitations of standard quasi-linear weighted neural networks are important to their success, and again we fall back on the empirical evidence that despite these limitations, such models have proven their value on a range of important real-world problems, that generally fall within the scope of the kinds of functionality present in the mammalian neocortex (e.g., visual object recognition, language prediction).

## Beneficial biological constraints on constraint satisfaction search

The final contribution of this paper is to explore the potential impact of a set of biologically motivated constraints on the constraint satisfaction search through activation space, in the context of the widely-studied traveling salesman problem (TSP). We compare three models: The original Hopfield network (as in [[@HopfieldTank85]]), a mean-field, rate-coded version of that model, and a network with biophysically-based spiking neurons that are used in the [[Axon]] model, based on the adaptive exponential (AdEx) conductance-based neuron ([[@BretteGerstner05]]).
